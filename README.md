# NekoEdytor

NekoEdytor to lekki edytor tekstu i kodu dla Androida tworzony przez **The Path of the Nyaa**.

Aplikacja została zaprojektowana do wygodnej pracy z lokalnymi plikami na urządzeniu, z obsługą wielu dokumentów, różnych kodowań, podglądów oraz narzędzi przydatnych podczas edycji tekstu i kodu.

## Pobieranie

Oficjalne pliki instalacyjne są publikowane wyłącznie w sekcji **Releases** tego repozytorium oraz w kanałach wskazanych przez The Path of the Nyaa.

> Nie instaluj plików APK podpisanych innym certyfikatem ani zmodyfikowanych przez osoby trzecie.

Aktualna linia wydań: **NekoEdytor 1.x**

Identyfikator aplikacji: `pl.pathofthenyaa.nekoedytor`

## Najważniejsze funkcje

- edycja wielu dokumentów w kartach,
- obsługa plików przez Android Storage Access Framework,
- odzyskiwanie sesji i niezapisanych zmian,
- obsługa UTF-8, UTF-8 BOM, UTF-16 LE/BE, Windows-1250 oraz ISO-8859-2,
- podświetlanie składni wielu formatów i języków,
- wyszukiwanie i zamiana z obsługą wyrażeń regularnych,
- formatowanie JSON i XML,
- podgląd Markdown, JSON oraz XML,
- porównywanie tekstu w widoku Diff,
- konfigurowalne skróty i panele narzędziowe,
- język polski, angielski i rosyjski,
- tryb jasny, ciemny i dodatkowe warianty wyglądu,
- Kronika Nekorium.

## Instalacja

1. Otwórz najnowsze wydanie w sekcji **Releases**.
2. Pobierz plik `.apk`.
3. Jeśli Android o to poprosi, zezwól przeglądarce lub menedżerowi plików na instalowanie aplikacji z tego źródła.
4. Zainstaluj NekoEdytor.

Aktualizację można instalować bez usuwania poprzedniej wersji, o ile została podpisana tym samym oficjalnym kluczem.
